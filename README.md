# Aayam — Strength Studio

A modern, high-performance web experience for **Aayam**, a premier strength & conditioning studio located in Indiranagar, Bengaluru.

## ⚡ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Motion](https://motion.dev/)
- **Smooth Scrolling:** [Lenis](https://lenis.darkroom.engineering/)

## 🚀 Getting Started

### Installation

```bash
npm install
# or
pnpm install
```

### Development

```bash
npm run dev
# or
pnpm dev
```

### Production Build

```bash
npm run build
```

## 🏋️ Features

- **Curated Brand Identity:** Custom typography, earthy tones, and editorial aesthetics.
- **Fluid Micro-interactions:** Smooth buttery scroll using Lenis and Framer Motion spring physics.
- **Interactive Schedule & Pricing:** Real-time membership picker with India-friendly tiered options.
- **Responsive & Accessible:** Fully optimized across mobile, tablet, and ultra-wide displays with reduced-motion support.
